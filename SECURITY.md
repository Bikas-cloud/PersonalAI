# Security Policy

## Overview

PersonalAI is an evolving open-source project. We take security reports seriously and appreciate responsible disclosure.

## Supported Versions

| Version | Supported |
|---|---|
| Latest code on `main` | Best-effort security fixes |
| Older commits and snapshots | No guaranteed support |

This project has not published a stable release yet. The support policy will be updated when versioned releases become available.

## Reporting a Vulnerability

If you discover a potential security vulnerability in PersonalAI, please report it privately through GitHub's private vulnerability reporting feature.

To submit a report:

1. Open the PersonalAI GitHub repository.
2. Navigate to **Security > Advisories**.
3. Select **Report a vulnerability**.
4. Provide a clear description of the issue and the steps needed to reproduce it.

Please include, where possible:

- A summary of the vulnerability.
- The affected version, commit, or component.
- Steps to reproduce the issue.
- Potential security impact.
- Proof-of-concept details, if available.

**Please do not report security vulnerabilities through public GitHub Issues, Pull Requests, or Discussions.**

Do not include real passwords, API keys, access tokens, or other private user data in your report.

## Response and Disclosure

The project maintainer will review submitted reports and respond as reasonably practicable.

We encourage responsible disclosure. Please allow time for investigation and, where appropriate, a fix before publicly disclosing vulnerability details.

## Scope

This policy covers security vulnerabilities in the PersonalAI project and its maintained code.

Vulnerabilities in third-party dependencies should also be reported to their respective maintainers when appropriate.
